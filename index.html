uwu.js is an small little reactive-dom library
it enables you to write reactive variables right in your .html page like this:
<uwu id="var_name">0</uwu>
reference them on any other tag like this:
<p _uwu="var_name"></p>
and then modify them anywhere in your .js code like this:
var_name++;
That's it.
No JSX. No state() setup. No frameworks. No virtual-DOM.
uwu.js works how you think it would by default.

What uwu do:

  1. define reactive variables straight in the DOM with the <uwu> tag
  2. reference reactive variables on any HTML tag with the _uwu attribute
  3. bind reactive variables to <input> tags, currently supporting:
    • text
    • numbers
    • checkboxes
